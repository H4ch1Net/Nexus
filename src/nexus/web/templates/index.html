Local-first toolkit for cryptography analysis, OSINT, log analytics, and code enumeration. Everything below runs against the same local service layer as the nexus CLI, entirely offline.

Crypt Detect

Detect encodings, classical ciphers, and modern encryption from an input string.

Crypt Codec

Encode/decode base64, base32, base85, hex, URL, and ROT-N.

Hash Identifier

Identify the likely algorithm behind a hash string.

XOR Toolkit

XOR encode/decode, or brute-force a single-byte key.

IOC Extraction

Pull IPs, domains, URLs, emails, hashes, CVEs, and crypto addresses out of pasted text.

Secrets Scan

Scan text/code for exposed API keys, tokens, and private keys. Matches are redacted.

OSINT / Metadata

Extract EXIF and file metadata from an uploaded image.

Log Ingest

Ingest a JSONL log file into the local DuckDB database.

Log Queries

Run canned analytics queries against ingested logs.

Language ID

Identify the programming language of a code snippet.

Audit Trail

Browse everything this tool has analyzed - the same log the CLI writes to.
